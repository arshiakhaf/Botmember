# ربات تلگرامی اضافه‌کننده عضو با شماره موبایل

رباتی که با گرفتن **شماره موبایل**، کاربر را به گروه یا کانال اضافه می‌کند.

## ⚠️ قبل از هر چیز — مهم

- تلگرام اجازه اضافه کردن کاربر با شماره موبایل را **فقط برای کسانی می‌دهد که در
  «تنظیمات ← حریم خصوصی و امنیت ← گروه‌ها و کانال‌ها»** اجازه داده باشند
  (Everyone یا My Contacts).
- اضافه کردن افراد بدون رضایت، **اسپم** محسوب می‌شود و برخلاف قوانین تلگرام است؛
  ممکن است به محدودیت یا مسدود شدن کامل حساب شما منجر شود.
- از این ابزار **فقط برای مخاطبان خودتان** (مشتریان، اعضای خانواده، آشنایان و…)
  که رضایت دارند استفاده کنید. تعداد اضافه کردن را هم محدود نگه دارید تا حساب
  فلود نشود.

## چطور کار می‌کند؟

این پروژه دو بخش دارد:

1. **ربات (Bot API — توکن BotFather)**: پنل مدیریتی است که دستورهای شما را
   دریافت می‌کند (`/add`، `/target` و…).
2. **یوزربات (Telethon)**: یک حساب کاربری واقعی تلگرام است که عملیات واقعیِ
   اضافه کردن عضو را انجام می‌دهد.

> چرا این کار با توکن ربات به‌تنهایی ممکن نیست؟ چون **Bot API تلگرام اجازه
> اضافه کردن عضو با شماره موبایل را ندارد**. این کار فقط از طریق یک حساب کاربری
> واقعی (MTProto) انجام می‌شود.

## پیش‌نیازها

- پایتون 3.9 به بالا
- شماره موبایلِ **حسابی که قرار است اعضا را اضافه کند** (یوزربات)
- `API_ID` و `API_HASH` از [my.telegram.org](https://my.telegram.org)
  (بخش «API development» — یک اپلیکیشن بسازید و مقادیر را کپی کنید)
- توکن ربات از [BotFather](https://t.me/BotFather)

## نصب و راه‌اندازی

```bash
# 1) نصب وابستگی‌ها
python3 -m venv .venv
source .venv/bin/activate          # ویندوز: .venv\Scripts\activate
pip install -r requirements.txt

# 2) تنظیمات
cp .env.example .env
# فایل .env را ویرایش کنید:
#   BOT_TOKEN  = توکن ربات
#   API_ID / API_HASH = از my.telegram.org
#   (در صورت تمایل) ADMIN_IDS = آی‌دی عددی خودتان

# 3) لاگین حساب یوزربات (یک‌بار)
python setup_account.py
# شماره و کد تأیید را وارد کنید؛ فایل account.session ساخته می‌شود.

# 4) اجرای ربات
python main.py
```

بعد از اجرا، در تلگرام به ربات پیام `/start` بدهید.

## دستورها

| دستور | توضیح |
|---|---|
| `/target @channel` | انتخاب گروه/کانال مقصد (یا آیدی مثل `-100123...` یا لینک دعوت) |
| `/add 09123456789` | اضافه کردن یک عضو با شماره |
| `/addmany ...` | اضافه کردن چند عضو (جدا با کاما یا خط جدید) |
| `/status` | وضعیت اتصال حساب یوزربات |
| `/help` | راهنما |

نمونه:

```
/target @mychannel
/add 09123456789
/addmany 09123456789
09011112222
09351113333
```

## نکات فنی

- شماره‌ها را با اعداد فارسی یا انگلیسی، با یا بدون صفر اول و کد کشور وارد کنید؛
  به‌صورت خودکار به فرمت بین‌المللی (`+98...`) تبدیل می‌شوند. کد کشور پیش‌فرض
  از `DEFAULT_COUNTRY_CODE` در `.env` خوانده می‌شود.
- بین هر اضافه کردن ۲ ثانیه تأخیر اعمال می‌شود تا از فلود جلوگیری شود
  (مقدار `ADD_DELAY_SECONDS` در `main.py`).
- مقصد انتخابی برای هر ادمین جداگانه در `data/state.json` ذخیره می‌شود.
- فایل سشن (`account.session`) و `.env` حساس هستند؛ در `.gitignore` قرار دارند و
  نباید جایی منتشر شوند.

## ساختار پروژه

```
main.py           → ربات مدیریت (aiogram) + اتصال یوزربات
adder.py          → منطق اضافه کردن عضو با شماره (Telethon)
setup_account.py  → لاگین اولیه حساب یوزربات و ساخت سشن
config.py         → خواندن تنظیمات از .env
.env.example      → نمونه تنظیمات
requirements.txt  → وابستگی‌ها
```
