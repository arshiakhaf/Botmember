# ربات فروشگاهی تلگرام ☕️

یک ربات تلگرامی کامل و عمومی برای **تحویل پروژه دانشگاهی**؛ نمونه‌ای از فروشگاه
اینترنتی که مشتری کالا را انتخاب می‌کند، شماره کارت را می‌بیند، مبلغ را واریز
می‌کند، رسید را آپلود می‌کند و سفارش توسط ادمین تأیید می‌شود.

## قابلیت‌ها

### سمت مشتری (کاربر عادی)
- `/start` — منوی اصلی با دکمه‌های شیشه‌ای
- 🛍 **محصولات** — لیست کالاها + صفحه جزئیات هر کالا
- 🛒 **سبد خرید** — افزایش/کاهش تعداد، حذف کالا، خالی کردن سبد
- 💳 **ثبت سفارش** — نمایش پیش‌فاکتور، شماره کارت و نام صاحب کارت
- 📤 **آپلود رسید** — ارسال عکس/فایل رسید واریز و ثبت سفارش
- 📦 **سفارش‌های من** — مشاهده وضعیت سفارش‌ها (در انتظار / تأیید / رد)
- 📞 پشتیبانی و ℹ️ راهنمای خرید

### سمت ادمین (پنل مدیریت)
- `/admin` — ورود به پنل (فقط برای `ADMIN_IDS`)
- 📋 مشاهده سفارش‌ها + **مشاهده رسید پرداخت** + تأیید / رد سفارش
- ➕ افزودن کالای جدید (گفتگوی چندمرحله‌ای با FSM)
- 🗂 مدیریت کالاها (فعال/غیرفعال، حذف)
- 📊 آمار فروش (تعداد سفارش، کاربران، فروش تأیید شده)
- 📢 ارسال پیام همگانی به همه کاربران
- با تأیید/رد سفارش، **به مشتری اطلاع‌رسانی خودکار** می‌شود.

## نصب و اجرا

```bash
# 1) نصب وابستگی‌ها
python3 -m venv .venv
source .venv/bin/activate        # ویندوز: .venv\Scripts\activate
pip install -r requirements.txt

# 2) تنظیمات
cp .env.example .env
# در .env توکن ربات و (در صورت تمایل) ADMIN_IDS را وارد کنید

# 3) اجرا
python main.py
```

بعد از اجرا، در تلگرام به ربات `/start` بدهید.

> برای گرفتن آی‌دی عددی خودتان، به ربات دستور `/id` بدهید و عدد را در `.env`
> کنار `ADMIN_IDS` قرار دهید تا پنل `/admin` برایتان فعال شود.

## 🚀 فعال‌سازی ۲۴ ساعته روی سرور رایگان (بدون کارت بانکی)

اجرای محلی فقط تا وقتی سیستم شما روشن است کار می‌کند. برای اینکه ربات همیشه
آنلاین باشد، روی یک سرویس رایگان اجرا کنید:

### روش پیشنهادی: Render (رایگان، بدون نیاز به کارت)

1. به [render.com](https://render.com) بروید و با حساب **GitHub** ثبت‌نام کنید.
2. چون کد همین الان روی GitHub است، کافی است در Render روی
   **New → Blueprint** بزنید و مخزن `arshiakhaf/Botmember` را انتخاب کنید
   (برنچ `arena/01a05f86-botmember`). فایل `render.yaml` از قبل آماده است.
3. در مرحله تنظیم متغیرها، فقط `BOT_TOKEN` را وارد کنید (بقیه اختیاری‌اند).
   `WEBHOOK_URL` را خالی بگذارید — به‌صورت خودکار از `RENDER_EXTERNAL_URL`
   پر می‌شود.
4. **Apply** را بزنید؛ بعد از چند دقیقه سرویس بالا می‌آید و ربات فعال می‌شود. ✅
   آدرس سرویس چیزی شبیه `https://botmember-shop.onrender.com` خواهد بود.

> روش جایگزین: New → Web Service → مخزن را انتخاب کنید → Build Command:
> `pip install -r requirements.txt` → Start Command: `python main.py`.
> (یا با Dockerfile: Runtime = Docker)

**نکته keep-alive (مهم):** پلن رایگان Render اگر ~۱۵ دقیقه درخواستی نگیرد سرویس
را می‌خواباند. ربات با وب‌هوک کار می‌کند و با اولین پیام دوباره بیدار می‌شود
(چند ثانیه تأخیر؛ Telegram خودش دوباره ارسال می‌کند)، اما برای بدون‌تأخیر ماندن،
یک پینگ رایگان تنظیم کنید:

- در [cron-job.org](https://cron-job.org) (رایگان) یک job بسازید که هر ۵ دقیقه
  آدرس `https://botmember-shop.onrender.com/` را GET کند؛
- یا از [UptimeRobot](https://uptimerobot.com) (رایگان) با فاصله ۵ دقیقه.

### گزینه‌های دیگر

| سرویس | توضیح |
|---|---|
| **Koyeb** | مشابه Render؛ Web Service رایگان بسازید، `WEBHOOK_URL` را آدرس سرویس + `/webhook` بدهید |
| **HeavenCloud** | رایگان ۲۴/۷ بدون خواب (از طریق Discord؛ `discord.gg/getvps`) — برای aiogram هم مناسب است |
| **PythonAnywhere** | ⚠️ پلن رایگان فقط به دامنه‌های مجاز دسترسی دارد؛ به تلگرام وصل نمی‌شود، مناسب نیست |

برای Koyeb مقدار `WEBHOOK_URL` را برابر `https://<نام-سرویس>.koyeb.app` قرار دهید
(خود برنامه `/webhook` را به انتهایش اضافه می‌کند).

## ساختار پروژه

```
main.py            → نقطه ورود برنامه (حالت Polling محلی + Webhook برای هاست)
config.py          → خواندن تنظیمات از .env (توکن، وب‌هوک، کارت، ادمین‌ها)
store.py           → لایه داده (محصولات، سبد خرید، سفارش‌ها، کاربران) روی JSON
keyboards.py       → دکمه‌های شیشه‌ای (inline keyboards)
states.py          → حالت‌های FSM (دریافت رسید، افزودن کالا، پیام همگانی)
utils.py           → توابع کمکی (فرمت قیمت، اعداد فارسی/عربی، اِسکیپ HTML)
handlers/user.py   → هندلرهای سمت مشتری
handlers/admin.py  → هندلرهای پنل مدیریت
Dockerfile         → برای دیپلوی با داکر
Procfile           → برای Render/Koyeb
render.yaml        → دیپلوی یک‌کلیک روی Render
data/              → داده‌های ذخیره‌شده (خودکار ساخته می‌شود)
```

## نکات فنی

- داده‌ها بدون نیاز به دیتابیس، در فایل‌های JSON داخل پوشه `data/` ذخیره می‌شوند؛
  در ابتدای اجرا چند کالای نمونه به‌صورت خودکار اضافه می‌شود.
- جریان دریافت رسید و فرم‌های ادمین با **FSM** (aiogram) پیاده‌سازی شده است.
- اعداد فارسی/عربی در قیمت و موجودی به‌صورت خودکار به عدد تبدیل می‌شوند.
- رسیدهای آپلودشده علاوه بر ثبت در سفارش، در `data/receipts/` هم ذخیره می‌شوند.
