# ربات فروشگاهی تلگرام ☕️

یک ربات تلگرامی کامل و عمومی برای **تحویل پروژه دانشگاهی**؛ نمونه‌ای از فروشگاه
اینترنتی که مشتری کالا را انتخاب می‌کند، شماره کارت را می‌بیند، مبلغ را واریز
می‌کند، رسید را آپلود می‌کند و سفارش توسط ادمین تأیید می‌شود.

## قابلیت‌ها

### سمت مشتری (کاربر عادی)
- `/start` — منوی اصلی با دکمه‌های شیشه‌ای
- 🛍 **محصولات** — لیست کالاها + صفحه جزئیات هر کالا
- 🛒 **سبد خرید** — افزایش/کاهش تعداد، حذف کالا، خالی کردن سبد
- 💳 **ثبت سفارش** — نمایش پیش‌فاکتور، شماره کارت و نام صاحب کارت
- 📤 **آپلود رسید** — ارسال عکس/فایل رسید واریز و ثبت سفارش
- 📦 **سفارش‌های من** — مشاهده وضعیت سفارش‌ها (در انتظار / تأیید / رد)
- 📞 پشتیبانی و ℹ️ راهنمای خرید

### سمت ادمین (پنل مدیریت)
- `/admin` — ورود به پنل (فقط برای `ADMIN_IDS`)
- 📋 مشاهده سفارش‌ها + **مشاهده رسید پرداخت** + تأیید / رد سفارش
- ➕ افزودن کالای جدید (گفتگوی چندمرحله‌ای با FSM)
- 🗂 مدیریت کالاها (فعال/غیرفعال، حذف)
- 📊 آمار فروش (تعداد سفارش، کاربران، فروش تأیید شده)
- 📢 ارسال پیام همگانی به همه کاربران
- با تأیید/رد سفارش، **به مشتری اطلاع‌رسانی خودکار** می‌شود.

## نصب و اجرا

```bash
# 1) نصب وابستگی‌ها
python3 -m venv .venv
source .venv/bin/activate        # ویندوز: .venv\Scripts\activate
pip install -r requirements.txt

# 2) تنظیمات
cp .env.example .env
# در .env توکن ربات و (در صورت تمایل) ADMIN_IDS را وارد کنید

# 3) اجرا
python main.py
```

بعد از اجرا، در تلگرام به ربات `/start` بدهید.

> برای گرفتن آی‌دی عددی خودتان، به ربات دستور `/id` بدهید و عدد را در `.env`
> کنار `ADMIN_IDS` قرار دهید تا پنل `/admin` برایتان فعال شود.

## ساختار پروژه

```
main.py            → نقطه ورود برنامه (اتصال به تلگرام و اجرای polling)
config.py          → خواندن تنظیمات از .env
store.py           → لایه داده (محصولات، سبد خرید، سفارش‌ها، کاربران) روی JSON
keyboards.py       → دکمه‌های شیشه‌ای (inline keyboards)
states.py          → حالت‌های FSM (دریافت رسید، افزودن کالا، پیام همگانی)
utils.py           → توابع کمکی (فرمت قیمت، اعداد فارسی/عربی، اِسکیپ HTML)
handlers/user.py   → هندلرهای سمت مشتری
handlers/admin.py  → هندلرهای پنل مدیریت
data/              → داده‌های ذخیره‌شده (خودکار ساخته می‌شود)
```

## نکات فنی

- داده‌ها بدون نیاز به دیتابیس، در فایل‌های JSON داخل پوشه `data/` ذخیره می‌شوند؛
  در ابتدای اجرا چند کالای نمونه به‌صورت خودکار اضافه می‌شود.
- جریان دریافت رسید و فرم‌های ادمین با **FSM** (aiogram) پیاده‌سازی شده است.
- اعداد فارسی/عربی در قیمت و موجودی به‌صورت خودکار به عدد تبدیل می‌شوند.
- رسیدهای آپلودشده علاوه بر ثبت در سفارش، در `data/receipts/` هم ذخیره می‌شوند.
